## 实现与边界

Viewer 增加 Take Control / Resume。每次交接增加输入代次，撤销旧动作、清空待发队列，并等待 Worker 完成此前同步 HWND 消息和目标内 WM_CANCELMODE 后确认。确认前两侧输入禁用；每条输入消息再次核验代次、PID、Session、Desktop、Job 及 Default 输入桌面。旧代次请求在 Host 与 Worker 均拒绝，没有系统输入或 Default 桌面 fallback。

固定脚本仍是原有 26 个字符和一次点击，仅拆为间隔约 120 ms 的步骤供暂停验证。Resume 继续已完成进度，保留人类编辑，不重放全段；已请求但尚未接收的单次意图可以在显式 Resume 时重新授权。60 秒运行预算、3 秒租约保持不变，切换不续期预算。人类仅能操作合成 EDIT / BUTTON：ASCII、Backspace、客户区单击，最多 256 个事件、队列 16 项、命令有效期 2 秒、文本 512 字符。PNG 与帧元数据 SHA 一致，坐标支持边框与 CSS 缩放；尺寸、帧时效、边界不符则拒绝。

输入命令在私有 IPC 目录短暂存在，消费或控制权切换、Stop 时删除，包括写入未完成的临时文件；摘要不保存输入文字。截图可显示合成文字，保持忽略。页底并行输入框不转发、不读取其文字。没有添加依赖、框架、模型调用、VM、UIA、IME、粘贴、拖动、滚轮或通用应用支持；Host/Guest 协议、Workflow schema 与 Provider 未改动。新增代码与合成测试由本轮编写，没有导入第三方实现、旧素材或个人夹具，没有选择许可证。
