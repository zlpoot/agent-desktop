## 调试失败与修复

所有初次失败及私有诊断保留，不能计为成功：

- 初次预检因 PowerShell 模块路径发现失败而停止，未创建应用；固定脚本使用现有 PowerShell 及其自带模块路径，机器路径通过环境变量传入，不拼接脚本。
- 初始仅非单色采集的两次 `PROBE_READY` 是观察准备结果，包含初始化黑画面，已废弃其成功判据。等待启动稳定、线程 DPI 与非激活尺寸处理后，完整画面和 UIA 都确认可用；未扩大 2048 捕获上限。
- UIA 最初把合法 CEF 子进程误当根 PID 不一致；改为本次 Job 成员、Session、Desktop/原生 HWND 的逐元素检查。观察中过度读取也触发超时；只读控件角色过滤、有限树规模和调用间心跳，挂起 provider 仍由原看门狗终止。
- 初次 ValuePattern 返回后界面效果尚不可读，记录 `uia_value_effect_mismatch`；后续用有界效果读取。固定检索最终采用已验证目标 HWND 文字消息。没有在同一运行对未知效果盲目重试输入。
- 搜索先到综合页，且已选结果的行号变成可访问 `play` 图标；旧匹配两种都拒绝。根据实际页面切到单曲，并保留精确歌曲、歌手、原唱及排除 Live/翻唱的限制。
- 静态 `btn_pc_minibar_play` 在播放时仍不变，导致一次播放验证假阴性；私有截图和当前 Name 已显示 pause。修正为当前语义，未把该次误报解释为已证实登录/会员阻碍。
- 接管验证客户端最初尝试从 Default 读取隐藏 HWND 尺寸，被系统拒绝；改为隐藏 Worker 提供私有坐标，Host 仅转发受控协议，不读取/输入隐藏 HWND。
- 新的 Fake Viewer 检查最初使用 Playwright option `isDisabled()` 断言失败；DOM 的 disabled 属性已为 true，改为直接核验其原生属性后通过。两项新增 Python 测试首次因 Mock 缺少字段失败，补齐合成上下文后通过；未改变生产安全门来适配测试。
