## 五步体验与预期

1. 打开新地址，核对 A2 标题、主机与显式配置；下拉保持未选择，扫描/路径按钮禁用，候选为空。此时没有读取应用清单。
2. 明确选择“本机交互桌面”，检查“应用发现：可由操作者点击读取”和只读安装来源。选择本身不扫描。如果显示不可用，核对原因并反馈；不要为了通过验收而开放输入权限。
3. 点击“扫描 / 重扫”。查看限定来源覆盖结论、每个来源的完成情况、检查/拒绝条数；在“筛选已扫描应用”输入一个已安装应用名。筛选只处理现有结果，不再次扫描。明确选一个候选，核对版本、发布者、来源、安装实例和路径；同名多版本逐项核对。即使只有一个也不自动选择、确认或启动。
4. 输入一个你确认没有安装的应用名，检查缺失提示。完整只代表当前列出的限定来源，不代表全盘；不完整/不可用不能断言未安装。如果你已有可信应用路径，可在路径框填本地 `.exe` / `.lnk` 后点“指定路径”，只检查文件，不执行它；不用手写应用 JSON 或寻找 PID、HWND、窗口类。
5. 清空环境选择再选回本机，或在扫描期间点击“刷新配置”；确认旧候选/路径/筛选条件和覆盖清空，不自动重扫。已有可信工作区配置时可以切换，来源应标注“本机共享操作系统（只读，不继承启动许可）”；未配置时保持明确不可用，不强制改 JSON。重载页面恢复未选择。也可反馈一次权限、超时、路径或安装域错误是否易懂。

## 边界、停止和已知限制

- 只接入本机的开始菜单和当前用户/系统 App Paths 登记（安全 EXE / 快捷方式），沿用 P7-B 的 500 条共享预算、深度 5、5 秒超时及文件读取限制。达到限制、权限不足、过大 EXE、复杂快捷方式会如实降低覆盖，不扩大预算来伪造完整。
- 便携软件、商店包及未登记软件可能不在扫描来源里；“完整”不等于全机软件清单。手动路径检查是单个文件的检查，不是目录覆盖证明。网络路径、重解析路径和脚本包装器等仍拒绝。
- 默认只有本机环境；工作区仍需已有可信配置，此限制沿用 A1。虚拟机收集器未接入，绝不扫描本机作为 Guest 清单。工作区仅共享安装来源，不继承本机启动权，扫描不会创建工作区或打开应用。
- 禁止确认/启动/重验/撤销注册、任务/模型、桌面输入/Viewer、VM 控制和 Windows A5 实验；按钮禁用，Controller 和 localhost API 另外拒绝。候选始终只是“发现”，临时内存 Registry 不保存信任。
- 切换/刷新关闭旧页面会话并忽略晚到结果；已开始的只读 helper 可能执行到原有 5 秒上限后结束，不作为新环境结果显示，也不重试。
- 在启动终端 `Ctrl+C` 停止，关闭页面。候选和临时 Registry 随进程丢弃，不保存安装数据库或用户路径；没有用户应用需要终止。可重新运行 A1 的 `dashboard:preflight` 命令回到扫描关闭的阶段。
